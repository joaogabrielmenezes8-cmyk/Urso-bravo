# URSO BRAVO

Plataforma digital de preparação para carreiras policiais.

## Escopo inicial

- Soldado PMMG
- CFO PMMG
- Banco de questões validadas
- Simulados
- Plano de estudos
- Desempenho por disciplina, assunto e subassunto
- Caderno de erros
- Evolução futura para assinatura, turmas e modo professor
